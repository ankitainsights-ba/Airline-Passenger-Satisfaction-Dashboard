# ✈️ Airline Passenger Satisfaction Dashboard

## Project Overview
This project presents an interactive Power BI dashboard designed to analyze airline passenger satisfaction, customer experience, travel preferences, and flight delays.

The dashboard helps understand passenger behaviour and identify factors that influence customer satisfaction.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Key Performance Indicators (KPIs)
- Total Passengers
- Passenger Satisfaction Rate
- Average Flight Distance
- Average Departure Delay
- Average Arrival Delay

## Dashboard Features

### 1. Satisfaction by Travel Class
Analyzes passenger satisfaction across Business, Economy, and Economy Plus classes.

### 2. Satisfaction by Type of Travel
Compares satisfaction between Business and Personal travel.

### 3. Satisfaction by Age Group
Analyzes passenger distribution across different age groups.

### 4. Service Rating Scorecard
Compares average departure and arrival delay ratings.

### 5. Delay Impact on Satisfaction
Explores the relationship between flight delays and passenger satisfaction across service categories.

## Interactive Filters
- Travel Class
- Type of Travel
- Customer Type
- Gender
- Age Range

## Project Objective
The main objective is to understand passenger satisfaction patterns, analyze customer experience, and identify areas where airline services can improve.
